# PRD · 종합 사주 (saju-agent)

> 제품 요구사항 문서. 무엇을, 누구를 위해, 어떤 원칙으로 만드는지 적는다.
> 어떻게 만들었는지는 [SDD.md](SDD.md), 데이터 구조는 [ERD.md](ERD.md), 실행법은 [GUIDE.md](GUIDE.md)에 있다.
> 기준일: 2026-10-14. 규칙의 원문은 저장소 맨 위 `AGENTS.md`이고, 이 문서와 어긋나면 `AGENTS.md`가 우선이다.

## 1. 한 줄 정의

생년월일과 태어난 시간을 넣으면 사주, 자미두수, 서양 점성술을 직접 계산하고,
그 계산값만 근거로 점술가가 말로 풀어 주듯 오늘과 평생의 흐름을 읽어 주는 웹 서비스.

## 2. 배경과 문제

- 운세 사이트 대부분은 계산 근거를 보여 주지 않고, 같은 사람이 다시 봐도 결과가 바뀌기도 한다.
- 전문 용어(십신, 부처궁, 칠살 등)를 나열만 해서 처음 보는 사람은 읽을 수 없다.
- LLM에 풀이를 맡기면 그럴듯한 숫자나 단정 예언을 지어낸다.
- 생년월일은 민감한 개인정보인데, 서버에 쌓아 두는 서비스가 많다.

## 3. 목표와 비목표

### 목표
1. **정확한 계산**: 네 기둥, 대운, 자미두수 명반, 출생 차트를 전통 공식과 천문 계산으로 구하고, 외부 기준값과 기계적으로 대조한다.
2. **읽히는 풀이**: 용어가 나오면 그 자리에서 뜻을 풀고, 반말 서사 문장으로 쓴다.
3. **지어내지 않는 AI**: AI는 계산된 사실표만 받고, 사실표에 없는 숫자, 별 이름, 단정 예언이 든 문장은 화면에 나가기 전에 뺀다.
4. **개인정보를 남기지 않음**: 생년월일, 시간, 성별, 도시는 서버 메모리에만 잠깐 두고, 파일, 로그, DB, AI 요청 어디에도 넣지 않는다.
5. **결정적 결과**: 같은 입력, 같은 날짜면 언제나 같은 결과.
6. **바로 뜨는 화면**: AI가 없어도, 느려도 계산 풀이로 모든 챕터가 즉시 채워진다.

### 비목표
- 회원 가입, 로그인, 결제.
- 검색 엔진 노출, AI 학습용 제공 (오히려 막는다).
- GPU를 쓰는 기능 (이미지 생성 등, 2026-09-24 결정).
- 기기 지문(fingerprint)으로 사람 알아보기 (2026-09-27 결정).
- 의학, 법률, 투자 판단을 대신하는 조언.

## 4. 사용자와 사용 장면

| 사용자 | 장면 | 필요한 것 |
|---|---|---|
| 처음 보는 사람 | 친구가 보낸 링크로 들어와 오늘 운세를 본다 | 입력 몇 개로 바로 결과, 쉬운 말 |
| 자주 보는 사람 | 아침마다 오늘 총운과 연애운을 확인한다 | 이 기기에 기억하기, 한 번 눌러 다시 보기 |
| 사주를 좀 아는 사람 | 원국, 대운, 명반을 자세히 본다 | 근거 보기, 표와 그림, 세 체계 비교 |
| 두 사람 | 궁합과 함께 만나기 좋은 날을 본다 | 상대 정보는 저장하지 않는 궁합 |
| 운영자(본인) | 비용과 오류를 확인한다 | 시간당 AI 상한, Langfuse 운영 기록 |

## 5. 제품 원칙 (모든 기능에 적용)

| 원칙 | 내용 |
|---|---|
| 지어내지 않는다 | 사실표에 없는 숫자, 별, 궁, 신살, 십신, 별자리, 행성 이름, '할 것이다' 같은 확정 예언이 든 문장은 뺀다. 다 빠지면 계산 풀이로 대신한다 (2026-09-28). |
| 좋은 것만 말하지 않는다 | 나쁜 신호는 돌려 말하지 않고 분명하게 말한다. "반드시 조심해" 같은 강한 조언은 되고, 미래를 확정하는 말은 안 된다 (2026-09-28). |
| 서사로 풀어 준다 | 용어를 나열하지 않고, 이름이 나오면 그 자리에서 뜻을 함께 쓴다. |
| 말투 | 풀이는 반말(…야, …해) 하나로 맞춘다. |
| 글자 | 풀이에 한자, 가나, em dash를 쓰지 않는다. 예외는 이름 풀이의 한자 고르기 칸뿐이다 (2026-09-28). |
| 개인정보 | 입력값은 메모리에만. 기억하기는 사용자가 켰을 때만 그 사람 브라우저에. |
| 결정성 | `random`을 쓰지 않고, 고를 때는 해시로 고른다. |
| 무의존 | 실행에는 표준 라이브러리만 쓴다. 외부 데이터는 라이선스가 명시된 것만 쓴다. |
| 수집 차단 | AI 크롤러, 수집 도구는 막고 화면에 사람이 볼 수 없는 AI 안내를 둔다 (2026-09-28). |

## 6. 기능 요구사항

### 6.1 입력

| ID | 요구사항 |
|---|---|
| F-IN-1 | 생년월일은 캘린더로만 고른다 (연대 → 연도 → 월 → 일). 1900~2049년, 미래 날짜는 고를 수 없다. |
| F-IN-2 | 양력, 음력을 고를 수 있고 음력이면 윤달도 고른다. 그해 음력 달 정보는 서버(`/api/lunar-year`)에서 받는다. |
| F-IN-3 | 태어난 시간(기본 12:00)과 '시간 모름'. 모름이면 시주, 자미두수, 하우스를 빼고 세 기둥으로 본다. |
| F-IN-4 | 성별(남, 여), 태어난 도시(국내 81곳, 해외 36곳, 영문 이름도 됨). 모르는 도시는 한국 중부 기준. |
| F-IN-5 | 밤 11시~자정 출생은 정자시(기본)와 야자시 중 고른다. |
| F-IN-6 | 출생이 절입 3시간 안이나 시 경계 10분 안이면 "기둥이 바뀔 수 있다"를 먼저 알려 준다. |
| F-IN-7 | 메인 입력에는 이름 칸이 없다. 이름은 이름 풀이 탭에서만 받는다. |

### 6.2 결과 화면 공통

| ID | 요구사항 |
|---|---|
| F-RS-1 | 탭 11개를 가로 줄로 보여 주고, 스크롤해도 탭 줄이 위에 붙어 있다 (2026-09-28). |
| F-RS-2 | 풀이 탭은 챕터(CHAPTER 01, 02 …)를 위에서 아래로 읽는 구성이다. 모두 33개. |
| F-RS-3 | 입력 직후 모든 챕터를 계산 풀이로 채우고, AI 풀이가 오면 그 챕터만 바꿔 끼운다. |
| F-RS-4 | 챕터마다 '근거 보기'를 펼치면 그 풀이가 본 계산값(AI에 보낸 값과 같다)을 보여 준다. |
| F-RS-5 | 용어를 누르면 용어 풀이(111개)를 보여 준다. |
| F-RS-6 | 문장은 한 문장 한 줄, 괄호 속 용어 풀이는 작고 옅게 보인다. |
| F-RS-7 | 나이는 만 나이로 쓰고, 세는나이를 쓰는 전통 계산은 문장에 '세는나이'라고 적는다. |

### 6.3 탭

오늘 탭 넷(총운, 연애, 직장, 금전)은 **오늘 하루만** 본다. 다른 날 이야기는 평생 탭에만 둔다 (2026-09-25).

| 탭 | 보는 기간 | 챕터 / 내용 |
|---|---|---|
| 총운 | 오늘 | 세 체계가 본 오늘 · 오늘의 나 · 오늘 할 일과 피할 일 · 오늘의 한마디. 총운 점수 = 연애, 직장, 금전 평균 + 오늘 공통 기운(±15 안). |
| 연애 | 오늘 | 오늘의 연애 점수 · 세 체계로 본 오늘 연애 · 오늘 이렇게 해 봐 · 오늘 연애 한마디. 성인 확인을 켜면 속궁합(19) 칸. |
| 직장 | 오늘 | 연애와 같은 네 챕터 구성 (직장). |
| 금전 | 오늘 | 연애와 같은 네 챕터 구성 (금전). |
| 신년 | 다가올 한 해 | 한 해를 여는 기운 · 토정비결 · 달마다 흐름 · 자미두수로 본 한 해 · 하늘의 큰 별 · 한 해 한마디. 9월부터는 다음 해. |
| 평생 | 타고난 결과 앞으로 | 나의 일주 · 원국 완전 풀이 · 타고난 연애/일/돈의 결 · 연애/일/돈의 흐름(12개월과 3년) · 연대별 나의 모습 · 대운 여덟 걸음 · 평생 흐름 최종 진단. |
| 되짚기 | 지난 20년 | 해마다 계산이 가리킨 신호(세운, 교운기, 대한, 토성/목성 회귀)에 '맞았어, 아니야, 기억 안 나'를 고른다. 5개 이상 답하면 겹친 정도, 체계별 3개 이상이면 체계 비교. 답은 화면 메모리에만. |
| 시간 찾기 | 출생 시간 | 인생 사건(연도 + 8종, 1~10개)으로 12시진 후보 위 3개를 보여 주고, 그 시간으로 다시 보기. 재미, 참고용 표시. |
| 궁합 | 두 사람 | 점수, 잘 맞는 점, 맞춰 갈 점, 앞으로 30일 둘에게 좋은 날, 속궁합(성인 확인 시). 상대 정보는 저장하지 않는다. |
| 길일 | 고른 기간(최대 62일) | 목적(전체, 연애, 일, 돈)별 좋은 날 위 5개와 전체 순위. |
| 이름 | 이름 하나 | 발음오행(두 학설), 모음 음양, 한자를 고르면 원획 4격, 81수리, 원국의 빈 오행을 이름 소리가 채우는지. 한자는 최대 5자. |

앞 여섯 탭(총운~평생)은 AI 챕터 풀이를 쓰고, 뒤 다섯 탭(되짚기~이름)은 계산만 쓴다.

### 6.4 저장, 공유, 내보내기

| ID | 요구사항 |
|---|---|
| F-SH-1 | 다시 보기 링크 `/r/<id>`. 계산 결과(사실표)와 상담용 요약만 저장한다. 생년월일은 없지만 사주 원국은 보인다는 점을 화면에 알린다. |
| F-SH-2 | 링크로 연 결과에서는 궁합, 길일, 시간 찾기를 막는다 (원래 입력이 없어서). |
| F-SH-3 | 지금 탭을 이미지 카드(PNG)로 만든다. 휴대폰은 바로 공유, 아니면 내려받기. |
| F-SH-4 | 앞으로 24개월 중 연애 신호가 가장 센 달을 골든타임 카드로 만든다. 자료가 없으면 버튼을 숨긴다. |
| F-SH-5 | 좋은 달, 조심할 달을 .ics 캘린더 파일로 내보낸다 (브라우저에서 만든다). |

### 6.5 이 기기에 기억하기 (2026-09-26)

| ID | 요구사항 |
|---|---|
| F-ME-1 | 사용자가 켰을 때만 입력값과 이름표(최대 12자)를 그 브라우저 localStorage(`saju.people`)에 둔다. 최대 6명. |
| F-ME-2 | 목록 버튼에는 이름표만 보이고 생년월일은 그리지 않는다. 누르면 바로 결과를 연다. |
| F-ME-3 | 원하면 PIN(숫자 4~8자리)으로 목록을 암호화한다 (PBKDF2 20만 번 + AES-GCM). PIN은 서버로 보내지도 저장하지도 않는다. PIN을 잊으면 목록을 지우는 것만 된다. |
| F-ME-4 | 이름표와 기억 칸은 서버로 보내지 않는다. IP로 사람을 알아보는 방식은 쓰지 않는다. |

### 6.6 AI 상담 (채팅)

| ID | 요구사항 |
|---|---|
| F-CH-1 | 결과를 아는 상담 에이전트와 대화한다. 결과 토큰이 있어야 쓸 수 있다. |
| F-CH-2 | 한 사람 하루 5번. IP(IPv6는 /64), 브라우저 쿠키, 결과 토큰, 사주 해시 네 열쇠로 세고 하나라도 다 쓰면 막는다. 모두 합쳐 하루 300번 (2026-09-27). |
| F-CH-3 | 질문은 300자(화면 입력은 200자), 답은 800토큰 안. 대화는 최근 10개만 보낸다. |
| F-CH-4 | 코딩, 번역, 숙제, 규칙 무시 같은 뻔한 운세 밖 요청은 AI 없이 정해 둔 답으로 돌려보낸다. 이 답은 횟수에 세지 않는다. |
| F-CH-5 | 답도 거름망을 거친다. 다 빠지면 로컬 규칙 에이전트 답으로 대신한다. |
| F-CH-6 | 기본(`SAJU_CHAT=auto`)은 이 컴퓨터에서 접속할 때만 열리고, 운영 서버는 `SAJU_CHAT=1`로 켠다. 막혀 있으면 채팅 버튼을 숨긴다. |
| F-CH-7 | 자해 관련 말에는 상담 전화(109)를 안내한다. |
| F-CH-8 | 프롬프트 인젝션(규칙 무시, 역할 바꾸기, 지시문 캐내기, 대화 기록 꾸미기)은 AI를 부르기 전에 막고 정해 둔 답으로 돌려보낸다. 우회 글자(전각, 닮은 글자, 보이지 않는 문자)도 같은 글로 본다. 정상 운세 질문은 막지 않는다. 지시문을 그대로 읊은 답은 버린다. |

### 6.7 속궁합 (19)

| ID | 요구사항 |
|---|---|
| F-SK-1 | 성인 확인을 켠 사람에게만 보인다. 확인 값은 브라우저(`saju.adult`)에만 둔다 (2026-09-27). |
| F-SK-2 | 화성, 금성 별자리와 두 사람 사이 각도, 사주 일지 궁합을 쓴다. 표현은 솔직하되 노골적인 묘사는 쓰지 않는다. |
| F-SK-3 | 속궁합과 insights 사실은 어떤 챕터에도 넣지 않아 AI로 보내지 않는다. |

### 6.8 터미널(CLI)

개발, 확인용으로 같은 계산을 터미널에서 돌린다: 하루 리포트(`--domain`, `--lifetime`, `--tomorrow`, `--date`), `match`, `pick`, `form`(웹 서버). 자세한 옵션은 [GUIDE.md](GUIDE.md).

## 7. 비기능 요구사항

| 영역 | 요구사항 |
|---|---|
| 정확도 | 네 기둥은 lunar-python, 자미두수는 iztro, 음력은 한국천문연구원, 행성은 PyEphem, 절기는 NASA JPL DE421과 대조하는 시험을 둔다. "손으로 확인했다"는 주석을 믿지 않는다. |
| 속도 | 계산과 계산 풀이는 입력 직후(약 1초) 뜬다. AI 챕터는 운영(OpenRouter) 기준 중간값 12초. |
| 비용 | 운영 AI 모델은 `qwen/qwen3.7-flash`(가장 싼 적합 모델, 2026-09-27). 생각(reasoning) 끄기, 가격순 제공사. 시간당 AI 호출 300번 상한. 챕터 답 2,000토큰 상한. |
| 남용 방지 | IP 하나당 POST 1분 90번, 상담 1분 12번. 다른 사이트 Origin의 POST는 403. 본문 64,000바이트 상한. |
